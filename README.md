# دروسي

تطبيق أندرويد شخصي لتنظيم مواعيد الدروس المسائية: جدول الأسبوع، طلاب كل يوم، حالة الدفع الشهري أو بالحصة، تذكير ببداية ونهاية كل حصة وبمراجعة المدفوعات آخر الشهر، وويدجت على الشاشة الرئيسية للحصة الجاية.

## التثبيت

كل تعديل يترفع على `main` بيبني ملف `dorosi.apk` تلقائيًا وينزله في صفحة Releases.
افتح صفحة **Releases** من الموبايل، نزّل `dorosi.apk` وافتحه. أول مرة أندرويد هيطلب السماح بتثبيت التطبيقات من المتصفح.

التحديثات بتتثبت فوق النسخة القديمة من غير ما البيانات تضيع.

## البيانات

كل البيانات محفوظة على الموبايل بس (ملف JSON). من شاشة التذكيرات تقدر تحفظ نسخة احتياطية وتبعتها لنفسك، وترجّعها على أي موبايل.

## للمطورين

- Flutter، الكود في `lib/`. المنطق (الجدول والحساب والتذكيرات) في `lib/data.dart` و`lib/services/reminders.dart` ومتغطي باختبارات في `test/`.
- الويدجت: `android/app/src/main/kotlin/com/aboelkasem/dorosi/NextLessonWidget.kt`.
- التوقيع: مفتاح debug قياسي (`android/app/debug.keystore`، كلمة السر المعروفة `android`) عشان كل نسخة تتثبت فوق اللي قبلها. التطبيق مش منشور على Google Play.

```
flutter test
flutter build apk --release
```
